# A specification with no criteria heading

## Requirements

### Requirement 1: Something

**Objective:** As a caller, I want a thing, so that another thing happens.

The requirement is stated in prose and never reaches a criteria block, so
EARS-CriterionShall has nothing to key on and reports success while checking
nothing. That silence is what this rule turns into a finding.

## Notes

A fenced sample naming the heading must not satisfy the rule:
